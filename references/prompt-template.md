## 共同规则

- 每个候选版本使用一个独立提示词文件和一次图像生成或编辑调用。
- 所有最终可见内容都由图像生成模型完成；不得在调用后补写文字。
- 先写读者任务与关系，再写材质；语义段必须比材质段更具体。
- 使用正文最小必要事实，不把整篇文章粘进提示词。
- 参考图只提供真实羊毛毛毡材质、核心阶段标签与适中文字尺度，不提供人物、物件、主题、具体文字或布局。
- 不使用“高级感”“苹果风”“谷歌风”等空泛词，改写为可见的构图、色板和工艺。
- 不因为担心课件感而禁止清楚的箭头、标签、编号和对齐。
- 除非用户明确要求对应封面无字，否则封面标题必须与画面在同一次生成中出现；文章没有原标题时先生成忠实的推导标题。
- 除非用户明确要求正文无字，或计划记录了事实、安全、尊重风险例外，否则正文图默认选择 `1–3` 个短文字锚点，并与画面在同一次生成中出现。
- 只有上述无字条件成立时才使用“无文字”区块，并禁止模型自行添加标题、英文或装饰字符。
- 正文画幅未指定时直接写 `16:9`，不得保留 `4:3 / 16:9 / 3:4` 三选一占位符。
- 写提示词前排除窄带穿环、船锚挂带、三条窄带汇入中心环和整圈缝边的连续道路；三向交汇改用宽大重叠毡片，成长路径改用彼此分离的脚印、踏石或节点。
- 新生成时可把内置参考记为“图像 1”；定向编辑时必须把当前候选记为“图像 1”、内置材质与尺度参考记为“图像 2”，并同步改写参考边界中的图像编号。不得把“参考图不提供布局”错误套到当前候选上，也不得用参考图中的空牌清除候选文字。

新生成提示词都包含这段参考边界：

```text
图像 1 只是用户认可的真实羊毛毛毡工艺、核心阶段标签与适中文字尺度标尺。只继承密集、离散、非周期、方向随机且互相交错的短羊毛纤维，平整厚毡裁片的物理叠放、可见纤维切面、跨边锁边线、亚麻经纬、柔和接触阴影，以及核心标签和文字相对画布的尺寸与内留白；禁止复制图像 1 的人物、物件、主题、颜色位置、具体文字和构图。所有对象和文字都像真实手工制作的 3D 羊毛毛毡贴花。禁止 leather、suede、faux leather、embossed leather、tooled leather、leather grain、debossed or stamped surfaces、vinyl、rubber；禁止连续卷曲沟纹、漩涡、藤蔓、重复印模、圆滑封边、油边、滚边、管状包边、皮革鞍缝槽、窄亮倒角、塑料、黏土、泡沫、针织或毛绒玩具。
```

每个含文字的提示词都追加：

```text
文字不是说明或建议，而是最终画面中必须真实存在的对象。标题、标签牌和牌内文字必须与主场景在这一次图像生成中共同完成。每个列出的容器都必须有对应文字，不得留下空标签。字面是单独裁切的薄毛毡贴字或真实刺绣线迹，可见压实离散短羊毛纤维，并继承画面的光向、厚度和接触阴影；禁止凹刻、压印、烫印或皮革压字。所有字符逐字照录，不增字、不漏字、不改字、不拆错字、不生成伪文字或乱码。
```

## 强制文字区块

提示词中用以下固定结构单独列出所有允许出现的文字：

```text
【必须渲染的唯一文字 — MANDATORY TEXT】
1. 精确文字：“{逐字字符串}”
   所属容器：{左侧标签牌 / 第一个节点 / 主标题牌等}
   固定断行：{单行 / 逐行写出}
   形态：{厚毡切字 / 薄毡贴字 / 刺绣字}
   位置与层级：{明确说明}
2. 精确文字：“{逐字字符串}”
   所属容器：{唯一容器}
   固定断行：{单行 / 逐行写出}
   形态：{文字形态}
   位置与层级：{明确说明}

硬要求：
- 上述每个字符串必须出现在最终图像像素中。
- 上述每个容器必须有字，零空标签。
- 除上述清单外，画面中不得出现任何汉字、字母、数字、伪文字、签名或水印。
- 同级正文短标签按角色标尺保持从属且清楚，不因只有 1–2 个字而越级放大，也不低于对应可读下限。
```

在提示词最后再次加入：

```text
【生成前文字自检】
最终图必须逐项看见：“{文字 1}”、“{文字 2}”。
不得缺少任何一项；不得留下对应空牌；不得出现清单外文字。
若无法正确生成这些文字，不要用空标签替代。
```

当画面确定无字时改用：

```text
【文字】
无。画面中不得出现汉字、字母、数字、伪文字、签名或水印，也不要添加无语义空标签牌。
```

此无字区块不是正文和封面的常规备选。只在 `plan.md` 已记录“用户明确要求无字”或具体风险例外时使用。

## 封面文案决策

按以下优先级先把两种封面标题写入 `plan.md`，后续提示词逐字复制，不在生成阶段重新措辞：

1. 用户明确指定的标题；
2. 文章正式标题；
3. 根据核心命题、读者承诺与正文高置信原词提炼的推导标题。

用户指定标题与文章正式标题必须保留全部字符和标点。固定断行只是在字符之间插入换行，不能把逗号、冒号、问号等标点删掉或当成可省略的版式符号。

推导标题规则：

- 头条长封面通常 `8–16` 个汉字，可用一个必要标点，控制在 `1–3` 行；
- 分享页方形封面通常 `4–10` 个汉字，只保留同一核心名词、动作或问题；
- 不新增数字、时效、身份、效果保证、研究结论、热点词、英文副标题或正文不存在的因果；
- 在计划中记录标题来源、核心命题和至少一个逐字原文依据；
- 用户未明确要求无字时，不得把“无原标题”解释成“无文字”，也不得暂停等待确认。

## 其他定向迭代

### 图意太抽象

```text
保持原文事实和文章情绪，彻底替换当前晦涩物件。改用正文里的具体人物动作、真实日常场景、简洁关系结构或全球通用符号。读者必须在三秒内说出主角是谁、正在做什么、结果是什么。保留并逐字生成强制文字清单。禁止闸门、弯带、环、抽象模块和用途不明的机械装置。
```

### 关系不清楚

```text
保持对象、强制文字清单和材质，强化唯一阅读方向。用清楚的位置、尺度、粗箭头、编号或相同条件下的并列比较说明关系；删除装饰物。不要让颜色独自承担含义。
```

### 材质像皮革、塑料或黏土

```text
只修材质，保持语义、人物动作、全部精确文字、标签位置和构图不变。把所有彩色对象重建为平整厚羊毛毛毡裁片的分层叠贴：最大色块清楚可见密集、离散、非周期、方向随机且交错的哑光短羊毛纤维；至少一处可见毡片厚度、纤维切面和轻微毛边；关键轮廓的独立 blanket stitch / whip stitch 线材具有穿刺点并跨过切边；保留短软接触阴影。删除全部皮革粒面、连续卷曲沟纹、漩涡、藤蔓、重复印模、蚯蚓状凸线、圆滑封边、油边、滚边、管状包边、鞍缝凹槽和窄亮倒角。禁止 leather、suede、faux leather、embossed leather、tooled leather、vinyl、rubber、塑料、黏土、泡沫、针织和长绒。
```

### 像儿童玩具

```text
保持图意和全部精确文字，降低饱和度，减少圆润装饰和无关配件，使用更利落的手工切边、清楚层级和符合文章严肃度的人物姿态。不要删除必要符号、数字或关系。
```

### 正文文字过大

```text
这是正文注释，不是封面标题。保持主场景、全部精确文字、标签位置、语义和既定标签层级不变，只把超出对应范围的标签与文字缩回：普通辅助标签在 470px 宽预览下字面目标 11–14px、绝不超过 15px；单行 3–4 字的核心阶段标签目标 16–19px、绝不超过 20px，超过 4 字且计划确认必须双行时每行 11–13px；微型页签目标 8–10px、绝不超过 11px；关键数字绝不超过 18px。1–2 个字也不得放大填满标签。普通辅助标签与微型页签的文字宽不超过容器宽 72%，核心阶段标签不超过 78%；所有层级文字高不超过容器高 55%。不得把核心阶段标签误缩成普通辅助字号。
```

### 文字与画面割裂

```text
保持核心命题和逐字文字清单，重新设计文字与主视觉的共同构图。让二者共享明确的基线、承托、围合、路径指向、前后遮挡或形状呼应；文字本身是有纤维、厚度和短软阴影的毛毡对象。禁止把平面标题放在一块空白区域、把无关插图放在另一侧。
```

### 容器内文字偏位

```text
保持所有精确文字、容器数量、语义和全局构图不变。只修正图像中的毛毡文字排版：每段文字必须属于指定容器，固定断行，文字块中心与容器内框中心水平和垂直对齐，四周内边距均衡；不贴边、不溢出、不跨框、不被针脚遮挡。每个指定容器必须有字。
```
