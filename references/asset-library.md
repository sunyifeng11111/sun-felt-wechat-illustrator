## 选择顺序

资产库提供的是可写入提示词的语义词汇，不是可直接拼贴的图片。

每张图按以下顺序选主角：

1. 正文里已有的具体人物、物件或动作；
2. 全球通用且一一对应的符号；
3. 熟悉的关系结构，如时间线、前后对比、步骤箭头；
4. 只有前三项都不能准确表达时，才使用动作隐喻。

毛毡只改变视觉材质，不改变符号的公认含义。不得为了原创而发明需要读者猜测用途的机械装置。

### 皮带与扣件风险预检

以下组合即使语义似乎成立，也很容易被生成模型做成皮革制品，默认禁用：

- 窄长带穿过圆环、扣件或船锚；
- 三条或更多窄带汇入一个中心环；
- 整圈缝边的连续道路、跑道、缎带或波浪路径；
- 带有双线缝槽、滚边、管状边或窄亮倒角的长条与圆环；
- 用“锚点”一词直接推导出船锚和带扣，却没有真实海事语境。

替代方式：

- 三向交汇使用宽大平整圆片、圆角花瓣或直接重叠的厚毡裁片；
- 成长与行动使用彼此分离的脚印、踏石或独立节点；
- 流程使用宽而扁平的节点卡与短 running stitch 连接，不让连接线本身成为主物；
- 只在少量受力边使用针脚，不沿长条四周完整包边。

每张图通常只用：

- 1 个主角或主符号；
- 1 个明确动作；
- 0–2 个辅助对象；
- 正文图默认 1–3 个短标签；只有用户明确要求无字或风险例外时为 0 个。

## 通用符号

| 语义 | 首选符号 | 推荐动作 |
|---|---|---|
| 时间、等待 | 时钟、沙漏、日历 | 指针前进、沙粒落下、日期被圈出 |
| 截止日期 | 日历、红色标记、倒计时牌 | 从目标日期向前倒排 |
| 步骤、流程 | 数字块、粗箭头、连续脚印 | 依次连接、逐步推进 |
| 目标 | 靶心、旗帜、奖杯 | 箭命中、旗帜插上终点 |
| 完成、正确 | 绿色对勾、盖章 | 勾选、盖下完成印记 |
| 错误、风险 | 红叉、警示三角、裂痕 | 阻断、偏离、发出警报 |
| 查找、核对 | 放大镜、清单 | 放大关键小字、逐项核验 |
| 选择、比较 | 天平、左右并列的同类物 | 称量、在相同条件下对照 |
| 数据变化 | 柱形、折线、刻度尺 | 上升、下降、拉开差距 |
| 信息、知识 | 书、卡片、文档、文件夹 | 阅读、整理、讲给他人 |
| 输出、表达 | 对话气泡、讲解者、纸飞机 | 讲述、发布、交付 |
| 沟通 | 对话气泡、信封、引号 | 发送、回应、双向连接 |
| 灵感 | 灯泡、火花、闪电 | 点亮、迸发；仅在灵感确为主题时使用 |
| 协作 | 拼图、共同握住的物件、交接的手 | 拼合、共同托举、交接 |
| 系统、联动 | 咬合齿轮、循环箭头、闭合轨道 | 连续运转、反馈回流 |
| 阻力、门槛 | 台阶、门、路障 | 跨越、移开、降低或升高 |
| 聚焦 | 放大镜、聚光圈、单一靶心 | 对准、缩小范围 |
| 金钱、商业 | 金币、钱袋、阶梯、收据 | 累积、投入、回收 |
| 科技 | 芯片、屏幕、手机、连接节点 | 连接、处理、同步；不伪造真实 UI |
| 成长 | 台阶、树苗、刻度、逐渐变厚的路径 | 攀升、扎根、累积 |
| 情绪 | 简化人物、心、云、波浪、表情符号 | 观察、拥抱、放下、走出 |
| 内耗 | 线团、反复拉扯的绳、原地循环脚印 | 解开、停止拉扯、剪断循环 |
| 疗愈、修复 | 创可贴、缝合的心、被接住的人 | 包扎、缝合、拥抱 |
| 边界、拒绝 | 门、围栏、停止手势、关闭通知 | 关门、后退一步、坚定说不 |
| 能量 | 电池、能量条、太阳与月亮、体力姿态 | 充电、消耗、恢复 |
| 休息、恢复 | 床、月亮、树、躺下的人 | 睡眠、散步、深呼吸 |
| 自然、生长 | 树叶、树苗、雨滴、太阳、云 | 发芽、舒展、接受风雨 |

使用通用符号不是堆图标。只有符号与正文语义一一对应，并参与核心动作时才使用。

## 人物与场景

人物不是装饰。适合以下内容时优先使用简化毛毡人物：

- 情感、叙事和个人经历；
- 教程中的实际操作；
- 人际关系、边界、协作和沟通；
- 行为改变、习惯和选择；
- 需要通过姿态区分焦虑、放松、犹豫或坚定。

人物使用简化轮廓、清楚姿态和少量面部信息，不追求真人肖像。场景只保留理解动作所需的桌面、床、门、手机、书等物件。

精确软件界面、代码、医学结构、地图和数据仪表盘不能靠毛毡场景伪造。此类内容使用真实截图或正规图表；毛毡图只承担概念总览。

## 动作语法

优先画动作和结果，不画静态名词集合。

| 关系 | 推荐动作 |
|---|---|
| 输入到输出 | 放入、处理、讲出、交付 |
| 前后变化 | 拆开、整理、修复、点亮 |
| 因果 | 推动、触发、阻断、导致 |
| 流程 | 依次通过、交接、返回、完成 |
| 反馈 | 记录、回看、调整、再次行动 |
| 选择 | 对比、称量、分流、勾选 |
| 累积 | 堆叠、增长、逐日填满 |
| 协作 | 拼合、共同托举、接力 |
| 边界 | 关闭、挡住、退出、说不 |
| 情绪观察 | 看见、命名、允许经过 |

“三个人站在一起”不等于协作；“三个节点排成一排”也不等于流程。动作必须改变对象或推动关系。

## 文字与容器

文字是可见毛毡资产，不是后期平面图层。

正文图默认使用少量文字与画面共同表达，而不是先生成纯图再判断是否补字：

- 具象场景或通用符号图通常使用 `1–2` 个 `2–6` 字短标签；
- 流程、对比或框架图通常使用 `2–3` 个 `2–5` 字短标签；
- 优先使用相邻正文原词；忠实短称必须在计划中标记原文依据；
- 标签用于消歧、标阶段或点明结果，不把正文句子做成大标题条。

- **直接毛毡切字**：用于封面标题、大数字和步骤号；适合较粗、较大的字形。
- **薄毡贴字**：用于正文短标签；字是单独裁切的薄毛毡片，与牌面有清楚明度差、纤维和短软阴影，禁止凹刻、压印或烫印。
- **刺绣字**：只用于较短辅助信息或微型页签；按对应层级达到手机端可读下限，不为展示线迹而越级扩大字号。
- **绶带或路径承托**：只在标题确实与路径、成长、推进等语义相关时使用；不能为了装饰随意加横幅。

每个文字容器只承载一个逻辑标签。生成提示词必须同时说明：

1. 容器形状、位置与尺寸关系；
2. 容器中的逐字文字与固定断行；
3. 水平和垂直光学居中；
4. 四周均衡内边距；
5. 正文角色对应的目标字号和硬上限；
6. 禁止贴边、溢出、跨框、错配到其他节点或被针脚遮挡。

普通辅助标签外框优先为画布宽 `14%–18%`、高 `9%–12%`，470px 宽预览下字面目标 `11–14px`、硬上限 `15px`。核心阶段标签或多节点核心牌优先为宽 `20%–22.2%`、高 `15%–18%`；单行 `3–4` 字时字面目标 `16–19px`、硬上限 `20px`，超过 `4` 字且确认必须双行时改为每行 `11–13px`。微型页签优先为宽 `9.5%–12%`、高 `6%–8%`，字面目标 `8–10px`、硬上限 `11px`。正文文字块宽不超过画布 `20%`；普通辅助标签与微型页签的字面宽不超过容器宽 `72%`，核心阶段标签不超过 `78%`；所有层级字面高不超过容器高 `55%`。短词不能自动放大；长标签先删去非必要文字或合理断行。文字保持从属，但不能低于对应可读下限。

## 工艺词库

每次生成都使用：

- 3D felt appliqués；
- thick wool felt；
- dense, discrete, non-periodic, randomly oriented matted short wool fibers；
- tactile depth and thickness；
- hand-cut raw fiber edges with visible felt cross-section；
- flat thick felt pieces layered as appliqué, not molded or embossed；
- soft directional studio lighting；
- short, soft contact shadows；
- textured cream paper 或 light linen background。

缝线按语义使用：

- blanket stitch / whip stitch：关键外轮廓和受力边；独立线材有穿刺点并跨过或包住纤维切边；
- running stitch：流程连接线；
- cross stitch：极少量修补或强调；
- contrasting thread：深浅边缘需要分离时。

波浪边和锯齿边只用于生活方式、教育、母婴或轻松内容。严肃、商业、科技内容使用利落手工切边。

## 扩展与禁用规则

库中没有合适符号时可以扩展，但新资产必须同时通过：

1. **三秒复述测试**：只看图或只看草图，能说出主角在做什么；
2. **一一对应测试**：不会同时自然地解释成另一个常见概念；
3. **可毛毡化测试**：不用纤细线条、复杂建筑或精密机械也能成立；
4. **删文字测试**：删除标签后仍能认出主题和动作；标签只负责消歧；
5. **去材质测试**：去掉毛毡效果，信息关系仍然正确。
6. **皮革辨别测试**：100% 原图下纤维必须是离散随机细丝，不是连续压花沟纹、漩涡、藤蔓或皮革粒面。
7. **毛毡切边测试**：至少一处可见毡片厚度和纤维切面；封边、油边、滚边、管状包边或鞍缝凹槽直接失败。

默认禁用：

- 不明用途的闸门、环、弯曲带、抽象模块和虚构机器；
- 窄带 + 圆环 / 扣件 / 船锚、整圈缝边的连续道路，以及任何容易读成皮带、表带或滚边软垫的组合；
- 只靠颜色差异表达含义；
- 塑料纽扣和其他破坏毛毡可信度的亮面配件；
- 皮革、麂皮、仿皮、压花革、雕花革、皮革粒面、乙烯基、橡胶、连续卷曲压纹、油边、滚边、管状包边和鞍缝凹槽；
- 与主题无关的灯泡、齿轮、星星和装饰箭头；
- 为追求独特而替换掉更清楚的时钟、日历、人物或图表；
- 让读者必须先读完整段落才能理解的隐喻。
- 平面电脑字体、文字漂浮在容器外、同一组标签出现不同的居中方式。
