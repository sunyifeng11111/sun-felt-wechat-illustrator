## 视觉定位

使用真实手工羊毛毛毡贴花表现文章内容：有可触摸的厚度、压实短纤维、手工切边、锁边缝线和柔和接触阴影。

画面可以成熟、温暖、专业、活泼或克制，取决于文章；不要把所有文章固定成同一种“黑色毛毡产品摄影”。

材质服务信息。即使去掉毛毡纹理，人物、符号、步骤和关系也必须清楚。

## 参考图边界

`../assets/ai-text-flow-reference.png` 是用户认可的 AI 图文一体正文参考。它只提供：

- 密集、离散、方向随机的短羊毛纤维，厚毡贴花、纤维切边、跨边锁边缝线、亚麻底与柔光；
- 核心阶段标签、牌内适中文字的相对尺寸、内边距和从属层级；
- 文字应服从主场景、不能变成章节标题的视觉关系。

提示词必须明确：

> 图像 1 只是正文真实羊毛毛毡工艺、核心阶段标签与适中文字尺度标尺。只继承密集离散短羊毛纤维、厚毡纤维切面、跨边锁边针脚、亚麻经纬、柔和接触阴影，以及核心标签和文字的相对尺寸与内留白；禁止复制图像 1 的人物、物件、主题、颜色位置、具体文字和构图。禁止皮革、麂皮、仿皮、压花或雕花表面。

默认不把已生成的封面或正文图作为下一张的布局参考。系列一致性通过同一标尺、色板和工艺文本维持。

## 材质与工艺

每次生成都写入以下可见特征：

- 3D felt appliqués，手工裁切的厚羊毛毛毡贴花；
- 哑光、压实、密集、细短、断续、非周期、方向随机且互相交错的离散羊毛纤维；
- 可见厚度与分层，通常由 2–4 片平整厚毡裁片物理叠放形成，不做模塑或表面压花；
- 边缘保留纤维切面与极轻微毛边；不封边、不油边、不滚边、不做管状包边；
- 关键外轮廓或受力边有清楚、细致的 blanket stitch / whip stitch；独立线材具有穿刺点并跨过或包住切边，不沿凹槽模拟皮革鞍缝；
- 流程连接可使用 running stitch，但必须粗细清楚、数量克制；
- 平整的浅色薄毡背衬可帮助深色物体与背景分离，不做隆起滚条；
- 左上或侧上方大面积柔光；
- 向右下或背光方向落下的短、软、浅接触阴影；
- 暖奶油纹理纸、浅亚麻或与文章色调匹配的低对比底材；纸浆纤维或亚麻正交经纬必须可辨；
- 顶视或轻俯视，主体边缘保持清楚，不用强景深。

最大色块在 100% 原图下必须看见上述离散短纤维。连续弯曲沟槽、漩涡、藤蔓、重复印模、卷曲凸线、皮革粒面或窄亮倒角都不是毛毡纤维，直接失败。缝线是识别 3D 毛毡工艺的重要信号，但不需要每一条边都缝满。生活、教育和母婴内容可使用更圆润的裁片轮廓；商业、科技、数据和严肃内容使用更利落的手工裁片，二者都必须保留纤维切面。

## 毛毡文字系统

文字必须像与其他对象在同一工作台上制作和拍摄，继承相同的纤维尺度、光向、厚度和接触阴影。

按用途选择一种，不要在同一张图里混搭：

| 文字用途 | 首选形态 | 可见特征 |
|---|---|---|
| 封面主标题 | 厚毡切字 | 清楚粗字形、短纤维、1–3 毫米视觉厚度、轻微手工切边、短软投影 |
| 分享页封面标题 | 厚毡切字 | 比长封面更短、更集中，只保留一个标题层级和一个主焦点 |
| 封面副层级 | 薄毡贴字或克制刺绣字 | 字重略轻，但仍有纤维或线迹，不像印刷体 |
| 正文卡片标签 | 薄毡贴字或克制刺绣字 | 单独裁切的薄毛毡字贴在牌面，或使用真实刺绣线迹；与牌面共享光向和材质，禁止凹刻、压印、烫印 |
| 数字、单位、步骤号 | 厚毡切字 | 轮廓简洁、对比清楚、数字和单位保持同一基线 |
| 极小辅助信息 | 刺绣字 | 线迹清楚、数量少；允许牺牲部分纤维细节，不为展示材质而放大 |

毛毡字不是把普通字体加粗：

- 文字、所属标签牌与主场景在同一次图像生成中完成，不把标签牌留空；
- 字面有压实短纤维，而不是纯色像素；
- 封面标题与关键数字有可见厚度、柔和漫反射边缘和短接触阴影；正文标签可用更薄的独立毛毡贴字或刺绣效果；
- 允许极轻微手工不规则，但字形、笔画和断行必须正确；
- 只有足够大的标题字可以使用少量边缘针脚；普通辅助标签和微型页签不要让针脚穿过笔画；
- 文字颜色与背景达到清楚对比，不使用同明度近似色；
- 标签牌内的文字块水平与垂直居中，四周留出均衡内边距；
- 同一篇锁定一种标题形态和一种正文标签形态。

正文图默认不是无字插画。除非用户明确要求无字或存在事实、安全、尊重风险，每张正文图使用 `1–3` 个从属短文字锚点；场景或符号图通常 `1–2` 项，结构图通常 `2–3` 项。主场景先被看见，文字随后完成消歧或强调。

禁止把平面黑色电脑字、发光字、金属字、塑料字或印刷墨迹贴在毛毡场景上。禁止凹刻、压印、烫印或皮革压字。所有文字由图像生成模型与画面一体生成；正文标签使用较薄的独立毛毡贴字或真实刺绣，优先守住对应层级的可读范围。

### 正文标签标尺

正文文字是注释，不是标题。先看见人物、动作、路径或数据关系，再看见标签。

| 层级 | 标签外框 | 可见字形高度 | 470px 宽预览目标 |
|---|---|---|---|
| 普通辅助标签 | 画布宽 `14%–18%`、高 `9%–12%` | 服从 470px 预览标尺 | `11–14px`，硬上限 `15px` |
| 核心阶段标签 / 多节点核心牌 | 画布宽 `20%–22.2%`、高 `15%–18%` | 单行 `3–4` 字优先 | `16–19px`，硬上限 `20px` |
| 微型页签 | 画布宽 `9.5%–12%`、高 `6%–8%` | 服从 470px 预览标尺 | `8–10px`，硬上限 `11px` |
| 关键数字/步骤号 | 服从节点，不单独扩牌 | 不超过节点层级 | `12–16px`，硬上限 `18px` |

同时满足：

- 任一正文文字块宽度不超过画布 `20%`；
- 普通辅助标签与微型页签的文字宽度不超过所属标签外框 `72%`，核心阶段标签不超过 `78%`；所有层级文字高度不超过外框 `55%`；
- 标签左右内留白各至少外框宽 `12%–15%`，上下各至少外框高 `22%–25%`；
- 普通场景全部标签外框面积通常不超过画布 `6%`，三节点解释图最多 `12%`；
- `1–2` 个字也按同级字号，不自动放大填满空牌；
- 核心阶段标签超过 `4` 个汉字时先缩短；必须保留时使用两行，每行在 470px 预览下目标 `11–13px`，总字块不超过牌高 `55%`；
- 非 16:9 画幅优先保持标签约 `2.1:1–2.3:1` 的长宽比，并以 470px 预览标尺为准；
- 文字必须保持从属，但也必须达到对应层级的可读下限；材质细节弱或字形过小不能作为验收理由。

## 构图与人物

按信息任务选择构图：

| 任务 | 构图 |
|---|---|
| 单一概念 | 一个大符号或一个人物动作，主体清楚 |
| 流程 | 左到右、上到下或闭环；箭头和节点可见 |
| 对比 | 相同尺度与条件下左右或上下比较 |
| 时间 | 连续时间线、日历或时钟推进 |
| 场景 | 一个关键时刻，保留理解动作所需环境 |
| 情绪 | 简化人物姿态 + 一个环境或情绪信号 |

通常保留约 25–45% 安静空间。流程和数据图可以更紧凑，情感场景可以更呼吸；不要机械追求 50% 留白而删掉必要信息。

公众号头条长封面约 `2.35:1`；分享页封面固定 `1:1`，采用更少对象、更短标题和更居中的单一焦点；正文图未指定时固定 `16:9`。不要通过机械裁切长封面得到方形封面，也不要为了容纳更多节点静默改变正文比例。

人物使用简化毛毡轮廓、清楚姿态和少量面部信息，不做真人肖像。人物必须参与核心动作，而不是站在旁边配合氛围。

简洁结构图可以对齐、分栏、使用箭头和标签。禁止的是密集课件、无层级卡片墙和装饰图标，不是所有图表。

## 情绪色板

先由文章情绪选择一组，再锁定整篇。单图通常使用背景色、主色、强调色和最多两个辅助色。

| 体裁或情绪 | 推荐色板 |
|---|---|
| 冷静教程、专业干货 | 奶油白、深海军蓝或炭黑、雾蓝；珊瑚用于提醒，鼠尾草绿用于完成 |
| 商业、科技 | 冷象牙、墨蓝、钢蓝、低饱和橙；避免霓虹和玩具色 |
| 温暖治愈、个人成长 | 燕麦色、可可棕、灰蓝、鼠尾草绿、陶土红 |
| 情感失落、克制叙事 | 灰米、炭灰、雾蓝、暗酒红；降低饱和度 |
| 生活方式、创意 | 暖奶油、陶土、芥末黄、鼠尾草绿、灰蓝 |
| 教育、母婴、轻松内容 | 奶油、杏色、天蓝、薄荷绿、柔黄；保持准确，不自动幼儿化 |
| 严肃克制 | 米白、炭黑、板岩灰、低饱和深红；减少圆润装饰 |

颜色不能独立承担语义。正确/错误、前/后、高/低还要通过形状、位置、方向、数量或文字区分。

色名与色值只用于生成指导，不得显示在画面中。

## 题材模式

### 信息模式

- 轮廓更利落；
- 标签和数字优先清楚；
- 箭头、时间线、对照和编号可以直接出现；
- 3D 深度用于层级，不把流程变成难懂的实体迷宫。

### 情感模式

- 人物与姿态优先；
- 允许更柔和的边缘和更多环境呼吸；
- 情绪通过人物动作、距离和场景表达，不只用抽象色块；
- 不做通用“孤独背影走向光”的励志图库画面。

### 严肃模式

- 减少可爱表情、彩色纽扣、波浪边和玩具感；
- 使用克制几何、尊重性人物轮廓或安静静物；
- 低饱和、少对象、无俏皮装饰。

## 禁止漂移

禁止：

- 皮革、麂皮、仿皮、压花革、雕花革、皮革粒面、乙烯基、橡胶、塑料、黏土、泡沫板、树脂和亮面 3D 渲染；
- 长绒、羊羔绒，以及整幅画面漂移成毛线、针织或钩编材质；正文需要表现“内耗”时允许一团由粗毛毡绳制成的线团作为语义对象；
- 连续卷曲沟纹、漩涡、藤蔓、重复印模、皮革压花、面条、彩糖针、塑料碎屑或蚯蚓状高频凸纹；
- 圆滑封边、油边、滚边、管状包边、皮革鞍缝槽、压出的假针孔和窄亮面倒角；
- 与主题无关的纽扣、别针、星星、灯泡和齿轮；
- 画面像皮带扣、智能手表、道路障碍或用途不明的产品原型；
- 只靠抽象弯带、闸门、圆环和模块表达心理概念；
- 为避免“像 PPT”而删除必要文字、数字、箭头和结构；
- 平面电脑字体悬浮在毛毡画面上，或文字与容器明显不居中；
- 复杂背景、硬阴影、强透视、霓虹渐变、水印和乱码；
- 同一篇里纤维尺度、光向、人物造型或色温无理由漂移。
